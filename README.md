# 🛒 Bayo Store | E-Commerce Storefront

A modern, responsive e-commerce web application built using HTML5, CSS3, ES6+ JavaScript, and external REST APIs.

---

## 🌟 Features

* **Dynamic Product Rendering:** Fetches real-time product catalogs asynchronously via the **FakeStore API**.
* **Category Filtering:** Quick-filter items by Men's Fashion, Women's Fashion, Jewelry, and Electronics.
* **Instant Product Search:** Live title and category search filtering.
* **Interactive Cart Drawer:** Slide-out side drawer with quantity management (`+` / `-`), individual item removal, and real-time total calculations.
* **State Persistence:** Uses browser `localStorage` to preserve shopping cart state across page reloads.
* **Responsive Layout:** Mobile-friendly UI styled using modern CSS Grid and Flexbox layouts.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API:** FakeStore API
* **Icons:** FontAwesome 6
* **Deployment:** Netlify
